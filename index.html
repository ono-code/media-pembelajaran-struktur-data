Memahami Struktur Data

Struktur data adalah cara menyimpan, mengorganisasi, dan mengatur data di dalam memori komputer agar dapat diakses dan dimanipulasi secara efisien.

1. Array (Larik) Kumpulan elemen bertipe sama yang disimpan secara berurutan di memori dengan indeks linier (dimulai dari 0).
2. List (Daftar Terhubung) Elemen data dinamis tempat setiap elemen menyimpan nilai dan acuan (pointer) ke elemen berikutnya.
3. Stack (Tumpukan - LIFO) Prinsip Last In First Out (Yang terakhir masuk, pertama keluar). Contoh: Fitur Undo/Redo & Tumpukan piring.
4. Queue (Antrean - FIFO) Prinsip First In First Out (Yang pertama masuk, pertama keluar). Contoh: Antrean loket tiket, antrean cetak printer.

Penulisan Pseudocode

Pseudocode adalah deskripsi tingkat tinggi dari algoritma pemrograman komputer yang menggunakan konvensi struktural dari bahasa pemrogram formal, namun ditujukan agar mudah dibaca oleh manusia.

// Contoh Pseudocode: Menentukan Lulus / Tidak
ALGORITMA CekKelulusan
DEKLARASI:
nilai : INTEGER
ALGORITMA:
READ nilai
IF nilai >= 75 THEN
PRINT "LULUS"
ELSE
PRINT "REMEDIAL"
ENDIF

Model Arsitektur Komputer Von Neumann

Arsitektur Von Neumann terdiri dari 4 komponen utama: **CPU (ALU & CU)**, **Memori Utama (RAM)**, **Perangkat Input/Output**, dan **Bus Data/Instruksi**. Proses jalannya instruksi mengikuti siklus: **Fetch (Ambil) → Decode (Terjemahkan) → Execute (Jalankan)**.

Peran & Fungsi Sistem Operasi (OS)

Sistem Operasi (seperti Windows, Linux, Android) adalah perangkat lunak sistem yang mengelola sumber daya perangkat keras (*hardware*) dan perangkat lunak (*software*) serta menyediakan layanan umum untuk program komputer.

Manajemen Proses

Mengatur eksekusi program melalui penjadwalan CPU (CPU Scheduling) dan alokasi status proses (Ready, Running, Blocked).

Manajemen Memori

Layanan pengalokasian lokasi ruang alamat RAM untuk aplikasi agar tidak saling bertabrakan (Paging / Virtual Memory).

Manajemen Berkas & I/O

Mengatur struktur direktori, sistem berkas (NTFS, ext4), serta driver perangkat keras pembaca/penulis data.
